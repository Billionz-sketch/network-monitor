Each computer runs a small agent that checks in with this server every 20 seconds. This page shows who is online, how much traffic they use, how fast their connection is, and raises an alert when something goes wrong. Administrators sign in to see full details and send commands.

Manage

Administrator sign-in

Signing in switches this page from the basic view to the full view (IP addresses, hostnames, top remote hosts) and unlocks remote commands.

Alert thresholds

Commands available per client: status check, scheduled shutdown (10 s – 1 h, cancellable), log off, block / unblock an IP at the client's firewall. They run on the client's next check-in.

Connect a client

Any Windows, Mac or Linux computer can join. It needs Python 3 and one small package.

1 · Agentmeasures bandwidth, latency, loss, CPU
2 · Heartbeatsends it to this server every 20 s
3 · Serveraggregates, tracks presence, raises alerts
4 · Dashboardthis page, basic or full view
  1. Install the package (once): pip install psutil
  2. Download the agent: agent.py — save it anywhere.
  3. Run it from that folder (change the name, and use the client key you were given):

The client appears in the table within seconds. Add --dry-run to try remote commands safely (nothing is executed). Press Ctrl+C to stop and watch it turn offline.
